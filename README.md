## 🎯 Problem Statement

Many citizens, especially first-time voters, find the election process confusing.  
There is a lack of simple, interactive, and easy-to-understand guidance, which leads to low awareness and participation.

---

## 💡 Solution

CivicAI is an AI-powered assistant that simplifies the election process through:

- 💬 Conversational AI interaction  
- 📋 Step-by-step voting guidance  
- 📅 Election timeline explanation  
- 🌐 Multi-language support  

All delivered through a clean and user-friendly interface.

---

## ✨ Key Features

- 🤖 AI-based election assistant  
- 📋 Step-by-step voting guide  
- 📅 Election timeline overview  
- 🌐 Multi-language support (English & Hindi)  
- ⚡ Smart fallback system (works without AI API)  
- 🎨 Modern, responsive UI  

---

## 🛠 Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js, Express  
- AI: OpenAI API  
- Hosting: AWS EC2  
- Process Manager: PM2  

---

## 🏗 Architecture

User (Browser)

Frontend (HTML/CSS/JS)  
↓  
Backend (Node.js + Express)  
↓

## ⚙️ Setup Instructions

1. Clone Repository  
git clone https://github.com/ahmad24mliwala/civic-ai-assistant.git  
cd civic-ai-assistant/backend  

2. Install Dependencies  
npm install  

3. Create Environment File  
Create a `.env` file and add:  
OPENAI_API_KEY=your_api_key_here  

4. Run Application  
node server.js
